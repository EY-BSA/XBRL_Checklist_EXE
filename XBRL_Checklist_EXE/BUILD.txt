================================================
XBRL CoE Checklist 1-1  —  EXE 빌드 안내
================================================

■ 사전 준비
  Python 3.9 이상이 설치되어 있어야 합니다.

■ 의존 패키지 설치 (최초 1회)
  pip install pandas openpyxl pyinstaller

■ EXE 빌드 (이 폴더에서 실행)
  pyinstaller build.spec

  완료 후 다음 위치에 실행 파일이 생성됩니다:
    macOS / Linux : dist/XBRL_Checklist_1_1/XBRL_Checklist_1_1
    Windows       : dist\XBRL_Checklist_1_1\XBRL_Checklist_1_1.exe

  ※ dist/XBRL_Checklist_1_1/ 폴더 전체를 배포하세요.
     (단일 exe가 아닌 폴더 형태로 묶어야 내장 데이터가 함께 포함됩니다.)

■ 실행 방법
  XBRL_Checklist_1_1 실행 → 파일 선택 버튼으로 구조내려받기 xlsx 선택
  → 체크 실행 → 결과 저장 위치 선택

■ 내장 파일 (자동 포함)
  · Axis_Domain_Check.xlsx    — 3-1 체크 등에 사용하는 표준 참조 데이터
  · template/XBRL_CoE_Checklist_Result.xlsx — 결과 출력 템플릿

■ 출력 파일
  XBRL_CoE_Checklist_Result_{회사명}_{날짜}.xlsx
  — Checklist_1-1 시트의 14행부터 이슈가 기록됩니다.
  — 이슈가 없으면 14행 이하는 비어 있습니다.
================================================
